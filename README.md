# meta-grinn-astra

Yocto BSP layer for Grinn hardware based on the Synaptics Astra SoCs.

## Layer usage

For full instructions see the [Grinn Astra documentation](https://wiki.grinn-global.com).

## Changelog

See [CHANGELOG.md](CHANGELOG.md) for changes between releases.

Releases use `major.minor.patch` versioning scheme:

- `major` - Synaptics SDK bumps
- `minor` - new features, new machine support
- `patch` - bug fixes, minor corrections
